# 记账日记 H5

简洁手账风格的可交互原型：点账单本体插入正文，点右侧表情快速评价单笔消费。

在线预览：https://boooer25.github.io/accounting-diary-h5/

视觉样式参考用户提供的「喵喵双人攒钱」Figma：猫爪纸底、手绘描边、粉色按钮和便签小猫插画。样式位于 `theme.css`，参考稿原始导出素材位于 `assets/`。页面保留紧凑账单与自由正文，未增加新的信息模块。

- 快速评价：后悔了、很值得、一般般，可更换和清除。
- 评价会同步到已插入的账单标签，作品回看时保留。
- 支持自由文字、照片、账单备注和历史回看；取消独立贴纸入口与短句贴纸选择。
- 账单图片按原比例缩小，直接放在对应账单行的名称与金额之间，默认全部选中。点击取消，再点重新选用；已选为粉色边框与勾选标记，未选为淡色虚线与空心标记。
- 勾选的账单图片立即展示在日记正文下方，无需切换到回看；取消勾选即收起，账单原图保留。选择状态会保存，更换账单图片后默认选用新图。
- 下方图片支持鼠标或触屏拖动摆放；轻点或按回车使图片上浮置顶并显示「调大小」按钮，长按可直接调大小，提供大小滑杆及「小巧一点 / 刚刚好 / 夸张一点」预设。位置与大小自动保存，取消勾选后重新选用也会保留摆放，回看时沿用作品布局。
- 图片保持原比例，拖动限制在正文下方区域内。窄屏切换时会调整位置与大小以适配页面；作品回看只提供图片预览。
- 去掉账单金额与快捷评价之间的图片缩略图；重复插入账单或切换编辑/回看不会重复生成图片。
- 照片入口支持上传和调用手机后置相机；桌面端按浏览器提供的文件选择能力降级。
- 选图后可直接放入原图，或一键抠图，加白色轮廓后展示在正文下方；确认前可恢复原图。支持查看、移除、自动保存及历史缩略图。
- 抠图使用本机 Web Worker 运算，图片不发送到抠图服务；首次使用需联网下载模型（约 40 MB）及运行时，耗时依设备与网络而定。加载失败可重试或继续使用原图。
- 页面使用演示账单。日记、评价和上传图片只保存在当前浏览器，不上传到 GitHub。
- 不需要安装依赖；直接用静态服务器运行。GitHub Pages 从 main 分支根目录发布即可。

演示沿用已确认线框图中的 2026 年 11 月 16 日示例日期。

图片流程位于 `photos.js`，抠图工作线程位于 `photo-cutout-worker.js`。第三方组件说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。

- 顶部分享按钮生成当前日记的 PNG 图片，包含日期、心情、全文和已选照片，保留照片大小、位置和层级。支持系统文件分享的浏览器可直接分享给朋友，其他浏览器可下载或长按保存。分享前可预览，包含保存的当日全部账单（金额、备注、图片与评价），不包含编辑工具。
- 轻点下方照片有上浮、轻微放大和阴影动效，点击其他位置落回纸面，摆放位置保持不变。尊重系统减少动态效果设置。

- 「今日账单」整块随日记自动保存；历史日记保留保存时的账单副本，回看时完整展示并收起编辑按钮。只有账单、没有正文的日子也显示在历史列表。旧日记在仍有对应账单数据时补入账单记录。
